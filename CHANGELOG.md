# Changelog

## 0.1.1

- Add Chinese and English descriptions for the native DSH plugin information page.
- Export package metadata and locale resources, and include translations in installable archives.

## 0.1.0

- Scope-aware search, selected schema disclosure, and guarded native dispatch.
- Stable model-facing schemas without restricting the underlying registry.
- Chinese keyword aliases, source filters, full catalog pagination and schema versions.
- Optional owned MCP connections with private metadata caches and safe idle behavior.
- Preserve native media, IDs, metadata, guards, cancellation, and concurrent scheduling.
- Restore the previous native executor on unload/reload; preserve unsupported PTC/custom modes.
